# Tool Hire and Reservation Management

Built a tool rental management system in Java that allows customers to borrow and reserve equipment while ensuring availability through a date-based reservation system.

## Project Overview

This project simulates a tool-hire shop and provides functionality for managing inventory, customer records, and equipment reservations. The system tracks borrowed items, reservation periods, and customer information while preventing booking conflicts.

## Features

- Customer management
- Tool and inventory tracking
- Equipment reservations
- Reservation conflict checking
- File-based data persistence
- Multiple item types using inheritance

## Technologies Used

- Java
- Object-Oriented Programming
- Inheritance
- Polymorphism
- Maps and Arrays
- Scanner and PrintWriter
- UML Design

## What I Learned

- Designing class hierarchies using inheritance
- Using Maps for efficient data lookup
- Building a reservation system with conflict checking
- Reading and writing data using files
- Managing relationships between objects
